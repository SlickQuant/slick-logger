Detailed Description

Reads a file written by EncodedFileSink back as LogEntry values.

Each entry comes back as the sink saw it, so a sink renders it exactly as it would have then: give them to a FileSink to get the text file back.

EncodedLogReader reader("app.slog");
FileSink text("app.log");
while (const LogEntry* entry = reader.next()) text.write(*entry);
if (!reader.error().empty()) std::cerr << reader.error() << '\n';
