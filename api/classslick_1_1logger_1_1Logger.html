◆ flush()

void slick::logger::Logger::flush ( )
inline

Block until all log entries queued before this call have been written to all sinks.

Unlike shutdown(), it leaves the logger running, so logging can continue normally after flush() returns.

Primary use case: call flush() before unloading a shared library whose string literals are referenced by queued log entries. Because LOG_* with string literals stores a raw pointer into the caller's code segment, unloading the library while entries are still queued would leave dangling pointers that the writer thread would later dereference.

Does nothing if the logger has not been initialized.

◆ prepare_thread()

bool slick::logger::Logger::prepare_thread ( )
inlinenoexcept

Claim the calling thread's ring now rather than on its first log call.

Returns
Whether the thread has a ring: false when thread rings are off, the logger is not running, or every ring is taken

The first log call on a thread allocates its ring (LogConfig::thread_ring_size), and the ring's pages are then faulted in as it fills. This claims the ring and faults in every page now, keeping both off a latency-sensitive path. Works whatever the log level, unlike a warm-up call. Needed once per thread per init(); init() does it for its own thread.

◆ set_instance()

void slick::logger::Logger::set_instance ( Logger *  logger)
inlinestaticnoexcept

Redirect Logger::instance() to an external Logger.

Because slick-logger is header-only, every shared library (.dll/.so) and the host executable each compile in their own copy of Logger::instance(). Call this from a shared library's init function to make all LOG_* macros in that library route to the host's logger instead of the library-local one. Pass nullptr to restore the library-local singleton.

Thread-safety: uses atomic store/load with acquire-release ordering, so all initialization of the target logger is visible before any LOG_* call after set_instance() returns.

◆ stats_snapshot()

LogStats slick::logger::Logger::stats_snapshot ( ) const
inlinenoexcept

The most recent statistics sample.

Returns
The last published LogStats, or a zeroed one when statistics are off

Safe to call from any thread and at any time, including before init() and after shutdown(): it returns a copy of an immutable published sample, so no reader can observe a half-written one.

shutdown() clears the published sample, so this reads zeroed once the logger is stopped rather than serving the finished run's numbers. Read them before shutting down if you want them.

Never touches the logging hot path. It is not, however, guaranteed wait-free: the sample is held in a detail::atomic_shared_ptr, which is lock-free only where the implementation says so (MSVC and libc++ both use an internal lock), so a caller can briefly contend with the once-per-interval publish. That is the price of a snapshot that is race-free by the memory model rather than merely in practice; see publish_stats().

Enable the sampling with LogConfig::enable_stats.

const auto stats = Logger::instance().stats_snapshot();
if (stats.entry_queue_pct_max > 80.0) { ... }
