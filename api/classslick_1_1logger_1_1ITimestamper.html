Detailed Description

Source of the time stamped on every log entry.

now() returns nanoseconds since the Unix epoch, which is what LogEntry::timestamp holds and what TimestampFormatter and the pattern flags render as a wall-clock time. A timestamper on another epoch still works, but its entries then render as times counted from 1970.

It is called on every logging thread at once, and on the statistics thread, so it must be thread-safe, and it sits on the logging hot path, so it should be cheap. Derive from it for a stateful clock (a calibrated TSC, a simulated clock in a backtest), or pass a lambda or a chrono clock type straight to Logger::set_timestamper() without writing a class at all.
