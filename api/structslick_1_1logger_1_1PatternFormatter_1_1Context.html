◆ level

LogLevel slick::logger::PatternFormatter::Context::level = LogLevel::L_ERROR

The level the line reports, which is L_ERROR when the message could not be formatted regardless of what the entry was logged at.

Every level-rendering flag must read this rather than LogEntry::level, so l and L can never disagree about the same line.
